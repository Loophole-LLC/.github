## Projects

### [Bastillion](https://github.com/Loophole-LLC/Bastillion) &nbsp;[![Stars](https://img.shields.io/github/stars/Loophole-LLC/Bastillion?style=flat&label=stars&color=2ea043)](https://github.com/Loophole-LLC/Bastillion/stargazers)

A self-hosted SSH console that puts access, key management, and session recording in one place.
Source-available and free for up to 5 registered systems; annual licenses raise the limit —
see [pricing](https://loophole.company/pricing.html).

### [JAYCE](https://github.com/Loophole-LLC/Jayce) &nbsp;`AGPL-3.0-only`

A small prototype learner that classifies by comparing new inputs against labeled examples and
adjusts as it is corrected, rather than by backpropagation. Source, reproducible benchmarks against
backprop, and a chat demo where it learns from a local LLM.
Walk through it in an [interactive lesson](https://loophole.company/jayce-toy-learning.html).
